# Full Agent Canvas behind nginx

The VM runs the full Agent Canvas (`agent-canvas --public`) as the UI and backend, served behind an nginx reverse proxy at the domain with Let's Encrypt TLS termination. Nginx is the single public entry point, routing HTTPS to Canvas (port 8000), ntfy (port 8080), and LiteLLM (port 4000) on internal paths or subdomains. This avoids running any OpenHands UI locally on the user's laptop. The alternative of backend-only mode (Canvas UI on laptop, Agent Server on VM) requires a running laptop to manage automations and view conversations, defeating the always-on goal.

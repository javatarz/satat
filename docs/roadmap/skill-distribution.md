# Skill distribution

**Status:** Idea · **Source:** call on 2026-10-16

- Common skills ship to every container from one central source (open skills format, one repo),
  so every agent starts with the
  [right context](https://karun.me/blog/2025/11/06/intelligent-engineering-building-skills-and-shaping-principles/#context-is-everything).
- Each repo declares the skills it needs in a manifest, so one copy isn't committed into many
  repos and versions don't drift.
- Must work for every agent, not only Pi.
